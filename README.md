# LOGUZ Sitio Web

Sitio web institucional para la funeraria LOGUZ, construido con HTML, CSS y
JavaScript vanilla.

## Objetivo

Renovar la presencia digital de LOGUZ con una imagen seria, moderna y
profesional, mejorando:

- confianza de clientes potenciales
- alcance orgánico mediante SEO
- experiencia móvil y tasa de contacto

## Stack

- HTML
- CSS
- JavaScript vanilla

## Deployment

- GitHub Pages (actual)
- Netlify (objetivo adicional, manteniendo compatibilidad estática)

## Criterios de calidad

- Mobile-first y responsive completo
- SEO técnico básico por página
- Accesibilidad de navegación y contenido
- Rendimiento web medible
